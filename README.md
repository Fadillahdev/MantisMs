## 🚀 Deploy ke GitHub Pages (Gratis)

### Langkah 1 — Push ke GitHub
```bash
git add .
git commit -m "🎵 Music Mantis - initial deploy"
git push origin main
```

### Langkah 2 — Aktifkan GitHub Pages
1. Buka repo di GitHub
2. Klik tab **Settings**
3. Di sidebar kiri → **Pages**
4. **Source**: `Deploy from a branch`
5. **Branch**: `main` → `/ (root)`
6. Klik **Save**

### Langkah 3 — Tunggu ±1 menit
App akan live di:
```
https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/
```

## 🎵 Tentang Jamendo API

Musik diambil dari **[Jamendo](https://www.jamendo.com/)** — platform musik legal dengan lisensi Creative Commons.

- ✅ Gratis
- ✅ Tanpa iklan
- ✅ Legal (Creative Commons)
- ✅ Selalu update (600K+ lagu)

Untuk API key pribadi (opsional):
1. Daftar gratis di [devportal.jamendo.com](https://devportal.jamendo.com/)
2. Ganti `JAMENDO_ID` di `index.html` dengan key milikmu
